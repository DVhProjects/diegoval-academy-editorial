# Política editorial

## Métrica de éxito
Ganar una audiencia que encuentre información original, útil, verificable y accionable: seguimiento, clics en fuentes oficiales, compartidos y visitas a la página (no sólo vistas).

## Miércoles
1. Buscar 10+ candidatos si las fuentes lo permiten.
2. Excluir: vencidos, beneficios vagos, elegibilidad irrelevante, fuente únicamente secundaria.
3. Priorizar financiación real y elegibilidad internacional, claridad de requisitos y tiempo suficiente para solicitar.
4. Seleccionar 1, anotar argumentos y 2 alternativas para historial editorial.
5. En la imagen: nombre oportunidad, quién aplica, beneficios críticos, fecha y primer paso. En el post: detalles y links.

## Viernes
Examinar documentos/regulaciones recientes, programas de financiación y recursos para postulación a PhD. Identificar evidencias y proponer un consejo accionable. Alternar categorías sin forzar temas poco relevantes.
- Tendencia europea → evidencia concreta → aplicación a una trayectoria académica.
- Tema de tesis → problema + posible pregunta + método tentativo + dónde encontrar datos.
- PhD career → acción concreta + requisitos reales + ejemplo general.
- Research opportunity → programa o red + mecanismo real de participación.

## Evitar
- Novedad no verificada: no llamar una tendencia "hot" sólo por intuición.
- Marketing exagerado: "beca garantizada", "estudia gratis" cuando no sea exacto.
- Mezclar oportunidades abiertas con estrategias especulativas.
- Publicar el mismo tipo de tema todos los viernes.
- Redacción genérica y textos superpuestos a fotos de IA.
